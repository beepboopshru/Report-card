# Student Report Card App — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Vite+React+Convex web app that lets ScienceUtsav teachers score students against per-kit rubrics for all 159 C-STEM kits and download PDF report cards.

**Architecture:** Single-page React app on Vite, Convex for database + auth (Password provider), `@react-pdf/renderer` for client-side PDFs. Admin role decided by email allowlist (env var). Rubric content for all 159 kits is generated by a one-shot Node script from the C-STEM PDF and seeded into Convex via an admin-triggered mutation. Each scoring row is one row per `(student, kit)` — re-scoring overwrites silently.

**Tech Stack:**
- Vite 5, React 18, TypeScript 5, React Router v6
- Tailwind CSS v4
- Convex (current), `@convex-dev/auth` Password provider
- `@react-pdf/renderer`
- Vitest + React Testing Library

**Source spec:** [docs/superpowers/specs/2026-05-24-student-report-card-design.md](../specs/2026-05-24-student-report-card-design.md)

## Task 2: Parse C-STEM PDF into `data/kits.json`

**Files:**
- Create: `scripts/parse-kits-pdf.mjs`
- Create: `data/kits.json` (output)

The PDF has already been extracted to `kits.txt` via `pdftotext -layout`. The parser reads that file and produces structured JSON. The layout has kit-number rows interleaved with multi-line descriptions in a separate visual column, so the parser uses a two-pass approach: first collect all rows with their concept/name/category/subject/grade by matching the line that starts with the kit number; then sweep the description column (right of column ~92) line-by-line and assign description text to the kit row most recently seen on that page.

- [ ] **Step 1: Re-extract layout text into the repo**

```powershell

```

If `pdftotext` is missing on the executor's machine, the file is committed below — they can skip this step.

- [ ] **Step 2: Write the parser**

Create `scripts/parse-kits-pdf.mjs`:
```js
// Parses data/kits.layout.txt (output of `pdftotext -layout`) into data/kits.json.
// Layout assumption: each kit's metadata row starts with a number followed by
// "Concept Kit-Name Category Subject Grade ...". Descriptions live in a column
// that begins around character index 92 and span multiple lines per kit.

import { readFileSync, writeFileSync } from "node:fs";

const raw = readFileSync("data/kits.layout.txt", "utf8");
const lines = raw.split(/\r?\n/);

const CATEGORY_RE = /\b(Explorer|Discoverer)\b/;
const KIT_ROW_RE  = /^(\d{1,3})\s+(.+?)\s{2,}(.+?)\s{2,}(Explorer|Discoverer)\s{2,}(.+?)\s{2,}(\d+)\s+\d+\s+active/;

const kits = [];
let pendingDescStart = -1;

// First pass: identify kit rows and remember the description column boundary.
let currentPageKits = [];   // kit indices on the current "page" (between form-feed boundaries)
let descBuffer = new Map(); // kit-index → string[]

function flushPage() {
  for (const idx of currentPageKits) {
    const buf = descBuffer.get(idx) ?? [];
    kits[idx].description = buf.join(" ").replace(/\s+/g, " ").trim();
  }
  currentPageKits = [];
  descBuffer = new Map();
}

for (let i = 0; i < lines.length; i++) {
  const line = lines[i];

  if (/Page \d+ of \d+/.test(line)) { flushPage(); continue; }
  if (/^Kit No\./.test(line)) continue;       // header repeated each page
  if (/^\s*C-STEM/.test(line)) continue;
  if (/^\s*Generated /.test(line)) continue;

  const m = line.match(KIT_ROW_RE);
  if (m) {
    const [, kitNumber, concept, kitName, category, subject, grade] = m;
    const kit = {
      kitNumber: Number(kitNumber),
      concept: concept.trim(),
      kitName: kitName.trim(),
      category,
      subject: subject.trim(),
      grade: Number(grade),
      description: "",
    };
    const idx = kits.push(kit) - 1;
    currentPageKits.push(idx);
    descBuffer.set(idx, []);
    continue;
  }

  // Description column: anything indented past column ~92.
  if (line.length > 92 && currentPageKits.length > 0) {
    const text = line.slice(92).trim();
    if (text) {
      const idx = currentPageKits[currentPageKits.length - 1];
      descBuffer.get(idx).push(text);
    }
  }
}
flushPage();

// Sanity-check: must be exactly 159.
if (kits.length !== 159) {
  console.error(`Expected 159 kits, parsed ${kits.length}. Inspect data/kits.layout.txt manually.`);
  process.exit(1);
}

writeFileSync("data/kits.json", JSON.stringify(kits, null, 2));
console.log(`Wrote ${kits.length} kits to data/kits.json`);
```

## Task 3: Rubric generator

**Files:**
- Create: `scripts/generate-rubrics.mjs`
- Create: `convex/seed/kits.ts` (generated, committed)
- Create: `convex/seed/rubrics.ts` (generated, committed)

Each rubric has exactly 6 criteria in this fixed order:
1. Following instructions (universal)
2. Construction quality (universal)
3. Safety & material care (universal)
4. Concept understanding — *[kit's concept]* (kit-specific)
5. Scientific observation/exploration — *[kit's name]* (kit-specific, varies by category)
6. Communicating findings (universal)

- [ ] **Step 1: Write the generator**

Create `scripts/generate-rubrics.mjs`:
```js
import { readFileSync, writeFileSync, mkdirSync } from "node:fs";

const kits = JSON.parse(readFileSync("data/kits.json", "utf8"));

const UNIVERSAL = [
  {
    id: "following-instructions",
    label: "Following instructions",
    sub: "Procedural accuracy",
    c4: "Follows all steps in correct sequence independently, without reminders",
    c3: "Follows most steps correctly; needs one or two reminders",
    c2: "Follows steps with teacher guidance at several points",
    c1: "Unable to follow steps without continuous teacher support",
  },
  {
    id: "construction",
    label: "Construction quality",
    sub: "Build & technique",
    c4: "Builds neatly and accurately; final assembly works as intended on first try",
    c3: "Builds adequately; minor adjustments needed; final assembly works",
    c2: "Builds with significant teacher help; assembly partially works",
    c1: "Unable to complete the build without continuous help; assembly fails",
  },
  {
    id: "safety",
    label: "Safety & material care",
    sub: "Responsibility",
    c4: "Follows all safety rules; handles materials carefully; cleans workspace thoroughly",
    c3: "Follows safety rules with one reminder; cleans most of workspace",
    c2: "Follows safety rules with multiple reminders; partial clean-up",
    c1: "Disregards safety rules; leaves materials scattered",
  },
  {
    id: "communication",
    label: "Communicating findings",
    sub: "Verbal / written",
    c4: "Clearly communicates observations and conclusions using science vocabulary",
    c3: "Communicates findings adequately; uses some science vocabulary",
    c2: "Communicates in everyday language; limited science vocabulary",
    c1: "Cannot communicate findings clearly; very limited vocabulary",
  },
];

function kitSpecificCriteria(kit) {
  const concept = kit.concept || "the activity";
  const kitNameLower = (kit.kitName || "this kit").toLowerCase();
  const isExplorer = kit.category === "Explorer";

  return [
    {
      id: "concept-understanding",
      label: `Concept understanding — ${concept}`,
      sub: "Science concept",
      c4: `Accurately explains the ${concept} concept and connects it to a real-world application`,
      c3: `Explains the ${concept} concept with minor gaps`,
      c2: `Partially explains the ${concept} concept; needs prompting`,
      c1: `Cannot explain the ${concept} concept even with prompting`,
    },
    isExplorer
      ? {
          id: "observation",
          label: `Scientific observation — ${kitNameLower}`,
          sub: "Describing what happened",
          c4: "Accurately observes and describes what happened during the activity, unprompted",
          c3: "Describes most of what happened with minor prompting",
          c2: "Describes some observations; needs significant prompting",
          c1: "Unable to describe observations even with prompting",
        }
      : {
          id: "exploration",
          label: `Scientific exploration — ${kitNameLower}`,
          sub: "Investigating what could happen",
          c4: "Asks insightful questions and explores variations of the activity, unprompted",
          c3: "Explores variations of the activity with minor prompting",
          c2: "Tries one variation; needs significant prompting",
          c1: "Does not explore beyond following the given steps",
        },
  ];
}

function rubricFor(kit) {
  const [c4, c5] = kitSpecificCriteria(kit);
  return [UNIVERSAL[0], UNIVERSAL[1], UNIVERSAL[2], c4, c5, UNIVERSAL[3]];
}

// Emit convex/seed/kits.ts
mkdirSync("convex/seed", { recursive: true });
const kitsTs = `// AUTO-GENERATED by scripts/generate-rubrics.mjs. Do not edit by hand.
export type SeedKit = {
  kitNumber: number;
  concept: string;
  kitName: string;
  category: "Explorer" | "Discoverer";
  subject: string;
  grade: number;
  description: string;
};

export const SEED_KITS: SeedKit[] = ${JSON.stringify(kits, null, 2)};
`;
writeFileSync("convex/seed/kits.ts", kitsTs);

// Emit convex/seed/rubrics.ts (keyed by kitNumber + category so we can join after kits are upserted).
const rubricRows = kits.map(k => ({
  kitNumber: k.kitNumber,
  category: k.category,
  criteria: rubricFor(k),
}));
const rubricsTs = `// AUTO-GENERATED by scripts/generate-rubrics.mjs. Do not edit by hand.
export type SeedRubricCriterion = {
  id: string;
  label: string;
  sub: string;
  c4: string;
  c3: string;
  c2: string;
  c1: string;
};

export type SeedRubric = {
  kitNumber: number;
  category: "Explorer" | "Discoverer";
  criteria: SeedRubricCriterion[];
};

export const SEED_RUBRICS: SeedRubric[] = ${JSON.stringify(rubricRows, null, 2)};
`;
writeFileSync("convex/seed/rubrics.ts", rubricsTs);

console.log(`Generated ${kits.length} kits + rubrics.`);
```

export type CriterionScores = Record<string, number>;

export function totalOf(scores: CriterionScores): number {
  return Object.values(scores).reduce((sum, v) => sum + (Number(v) || 0), 0);
}

export function maxScore(criteriaCount: number): number {
  return criteriaCount * 4;
}

export function scoredCount(scores: CriterionScores, criteriaCount: number): number {
  const ids = Object.keys(scores).filter(k => scores[k] > 0);
  return Math.min(ids.length, criteriaCount);
}

export function gradeBand(pct: number): "Outstanding" | "Proficient" | "Developing" | "Beginning" {
  if (pct >= 90) return "Outstanding";
  if (pct >= 75) return "Proficient";
  if (pct >= 50) return "Developing";
  return "Beginning";
}

import { useParams } from "react-router-dom";
import { useMutation, useQuery } from "convex/react";
import { api } from "../../convex/_generated/api";
import { Id } from "../../convex/_generated/dataModel";
import Breadcrumbs from "../components/Breadcrumbs";
import { useEffect, useState } from "react";

export default function EditRubric() {
  const { kitId } = useParams<{ kitId: string }>();
  const kit = useQuery(api.kits.get, { kitId: kitId as Id<"kits"> });
  const rubric = useQuery(api.rubrics.getForKit, { kitId: kitId as Id<"kits"> });
  const update = useMutation(api.rubrics.update);
  const [criteria, setCriteria] = useState(rubric?.criteria ?? []);

  if (!kit || !rubric) return <p className="text-sm text-gray-500">Loading…</p>;

  function patch(idx: number, key: string, value: string) {
    setCriteria(prev => prev.map((c, i) => i === idx ? { ...c, [key]: value } : c));
  }

  async function save() {
    await update({ kitId: kit._id, criteria });

                          className="w-full border rounded px-3 py-2 text-sm" />

import { useEffect, useRef } from "react";

export function useDebounce<T extends (...args: any[]) => any>(fn: T, delay = 500) {
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null);
  useEffect(() => () => { if (timer.current) clearTimeout(timer.current); }, []);
  return (...args: Parameters<T>) => {
    if (timer.current) clearTimeout(timer.current);
    timer.current = setTimeout(() => fn(...args), delay);
  };
}

import { useEffect, useMemo, useState } from "react";

export default function ScoreSheet() {

  const sid = studentId as Id<"students">;
  const kid = kitId as Id<"kits">;

  const kit = useQuery(api.kits.get, { kitId: kid });
  const rubric = useQuery(api.rubrics.getForKit, { kitId: kid });
  const score = useQuery(api.scores.get, { studentId: sid, kitId: kid });
  const upsert = useMutation(api.scores.upsert);

  const [criterionScores, setCriterionScores] = useState<Record<string, number>>({});
  const [observations, setObservations] = useState("");

  useEffect(() => {
    if (score === undefined) return;
    setCriterionScores(score?.criterionScores ?? {});
    setObservations(score?.observations ?? "");

    debouncedSave(criterionScores, v);

  const criteriaCount = rubric?.criteria.length ?? 6;
  const max = maxScore(criteriaCount);
  const pct = max ? Math.round((total / max) * 100) : 0;
  const scored = scoredCount(criterionScores, criteriaCount);

  if (!student || !cls || !kit || !rubric) return <p className="text-sm text-gray-500">Loading…</p>;

  return (

        { label: "Classes", to: "/" },

        </div>
      </header>

                    <div className="text-right">
